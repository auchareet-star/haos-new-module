เส้นทางเบิก UC ตั้งแต่ขอ Authen Code ถึงได้เงินจาก e-Claim

รายละเอียดแต่ละด่าน

1
เวชระเบียน / ห้องบัตร

ตรวจสิทธิ

ทำอะไร

  • ตรวจสิทธิออนไลน์กับ สปสช. ด้วยเลขบัตรประชาชน 13 หลัก
  • ดูว่าเป็น UC จริง และหน่วยบริการประจำ (hmain) / ปฐมภูมิ (hsub) อยู่ที่ไหน
  • แยกให้ได้ว่าเป็น UC ในเขต, นอกเขต (ต้องมีใบส่งตัว) หรือกรณีฉุกเฉิน

ต้องอยู่ใน HA.OS

  • สิทธิของ visit = UC (ไม่ใช่สิทธิค้างจากครั้งก่อน)
  • รหัส hmain / hsub ตามผลตรวจสิทธิวันนั้น
  • ใบส่งตัว (Refer in) ถ้าเป็นนอกเขต

พลาดบ่อย: ใช้สิทธิที่ติดมาจาก visit เก่า ทั้งที่ผู้ป่วยย้ายสิทธิแล้ว ส่งไปจะติดเรื่องสิทธิไม่ตรงกับฐาน สปสช. ณ วันรับบริการ

2
เวชระเบียน / ห้องบัตร (หรือผู้ป่วยทำเองที่ Kiosk)

ขอ Authen Code (ยืนยันตัวตนเข้ารับบริการ)

ช่องทาง

  • เสียบบัตรประชาชนผ่านโปรแกรม Authen ของ สปสช. (Smart Card Agent)
  • ตู้ Kiosk ของโรงพยาบาล
  • แอป สปสช. / ThaiD สแกน QR
  • ไม่มีบัตร (เด็ก ผู้สูงอายุ ผู้พิการ ฯลฯ): ขอด้วยเลข 13 หลักผ่านหน้าเว็บ Authen พร้อมระบุเหตุผล
  • ฉุกเฉิน: ให้บริการก่อน แล้วขอ Authen ย้อนหลังภายในเวลาที่ สปสช. กำหนด

สิ่งที่ได้กลับมา

  • Authen Code รูปแบบ PP ตามด้วยตัวเลข เช่น PP1234567890
  • ประเภทบริการ (claim type) เช่น PG0060001 บริการทั่วไป
  • 1 Authen Code ใช้กับ 1 การมารับบริการ ห้ามใช้ซ้ำข้ามวัน

พลาดบ่อย: ผู้ป่วยเสียบบัตรแล้วแต่ Authen Code ไม่ถูกเก็บลง visit ใน HA.OS ตอนส่ง e-Claim ช่อง Authen ว่าง เคส OPD จะไม่ผ่าน

3
เวชระเบียน / ห้องบัตร

เปิด Visit และผูก Authen Code

ทำอะไร

  • ลงทะเบียนส่งตรวจ ได้ VN
  • บันทึก Authen Code + ประเภทบริการ ลง visit นั้น
  • เลือกคลินิก / ห้องตรวจ ตามนัดหรือ Walk-in

ต้องอยู่ใน HA.OS

  • VN, วันเวลามารับบริการ, คลินิก
  • สิทธิ UC + Authen Code บน visit เดียวกัน
  • เลขที่ใบส่งตัว (ถ้ามี)
4
พยาบาล OPD + แพทย์

ซักประวัติ ตรวจ รักษา

ทำอะไร

  • ซักประวัติ วัดสัญญาณชีพ
  • แพทย์ลงวินิจฉัยหลัก (ICD-10) และโรคร่วม
  • ลงหัตถการ (ICD-9-CM)
  • สั่งยา Lab X-ray และรายการค่าบริการอื่น

ต้องอยู่ใน HA.OS

  • Dx หลัก 1 ตัวเสมอ, รหัส ICD ถูกต้องตามปีที่ สปสช. ใช้
  • เลขใบประกอบวิชาชีพแพทย์ผู้ตรวจ
  • ยาต้อง map รหัสมาตรฐาน (TMT / รหัส 24 หลัก)
  • Lab / บริการพิเศษต้อง map รหัส ADP / หมวดค่าใช้จ่าย

พลาดบ่อย: visit ไม่มี Dx (แพทย์ไม่ได้ลง) หรือยาใหม่ยังไม่ map รหัสมาตรฐาน แฟ้ม ODX / DRU ออกมาไม่ครบ

5
พยาบาล Ward + แพทย์ + Coder เฉพาะ IPD

Admit, จำหน่าย, สรุปชาร์ต

ทำอะไร

  • Admit ได้ AN (ขอ Authen ตามเงื่อนไข IPD ของ สปสช.)
  • จำหน่าย: ลงวันเวลา, สถานะ (discharge status) และวิธี (discharge type)
  • แพทย์สรุป Discharge Summary
  • Coder ลง ICD-10 / ICD-9-CM ตามชาร์ต แล้วจัดกลุ่ม DRG ได้ค่า AdjRW

ต้องอยู่ใน HA.OS

  • AN ผูกกับ HN และ visit ที่ admit
  • วันเวลา admit / discharge, จำนวนวันนอน, วันลากลับบ้าน
  • Dx หลัก + โรคร่วม + ภาวะแทรกซ้อน ครบตามชาร์ต
  • น้ำหนักแรกรับ สำหรับทารกแรกเกิด

พลาดบ่อย: สรุปชาร์ตช้า ทำให้ส่งเกินกำหนด หรือ Dx ไม่ครบ DRG ออกมาต่ำกว่าที่ควรได้

6
การเงิน

ปิดค่าใช้จ่ายและลงลูกหนี้ UC

ทำอะไร

  • ตรวจรายการค่าใช้จ่ายของ visit / AN ให้ครบ
  • ตั้งเป็นลูกหนี้สิทธิ UC (ผู้ป่วยไม่ต้องจ่าย ยกเว้นรายการที่สิทธิไม่ครอบคลุม)
  • แยกส่วนที่ผู้ป่วยต้องชำระเอง (ถ้ามี)

ต้องอยู่ใน HA.OS

  • ค่าใช้จ่ายแยกตามหมวดของ สปสช. (ใช้สร้างแฟ้ม CHT / CHA)
  • ยอดเบิกได้ / เบิกไม่ได้ แยกชัดเจน
  • visit ปิดแล้ว ไม่มีรายการค้างลง
7
ศูนย์จัดเก็บรายได้

ส่งออก 16 แฟ้ม และส่ง e-Claim

ทำอะไร

  • เลือกช่วงวันที่ / AN ที่จะส่ง แล้วตรวจข้อมูลก่อนส่ง
  • ส่งออกไฟล์ 16 แฟ้มจาก HA.OS
  • นำเข้าที่ e-Claim (eclaim.nhso.go.th) หรือส่งผ่าน FDH ของ สธ. ซึ่งส่งต่อให้ สปสช.
  • ส่งให้ทันกำหนด (ปกติภายใน 30 วันนับจากวันรับบริการ / วันจำหน่าย ส่งช้าจะถูกลดอัตราจ่าย)

ตรวจก่อนส่ง

  • ทุก visit OPD มี Authen Code
  • ทุกรายมี Dx หลัก
  • ยอดเงินในแฟ้ม CHA ตรงกับ CHT
  • ไม่ส่งซ้ำ visit / AN ที่ผ่านไปแล้ว
8
ศูนย์จัดเก็บรายได้ + ทุกหน่วยที่ต้องแก้ข้อมูล

ตามผล แก้ไข และรับเงิน

ทำอะไร

  • ดาวน์โหลดรายงานผลการตรวจสอบ (REP) จาก e-Claim
  • รายการที่ติด C: ส่งกลับไปให้ผู้รับผิดชอบด่านนั้นแก้ใน HA.OS แล้วส่งใหม่
  • รายการที่ถูกปฏิเสธ: พิจารณาอุทธรณ์
  • รับ Statement (STM) แล้วกระทบยอดกับลูกหนี้ UC

หลักการแก้

  • แก้ที่ต้นทางใน HA.OS เสมอ ไม่แก้เฉพาะในหน้าเว็บ e-Claim
  • ถ้าแก้แค่ปลายทาง ครั้งหน้าข้อมูลผิดแบบเดิมจะกลับมาอีก

ผลที่ได้จาก e-Claim

ผ่านรอรวมใน Statement แล้วรับเงินโอน ไม่ต้องทำอะไรเพิ่ม
ติด Cข้อมูลไม่สมบูรณ์หรือขัดกัน ดูรหัสข้อผิดพลาดใน REP แก้ที่ HA.OS แล้วส่งใหม่
ปฏิเสธการจ่ายไม่ตรงเงื่อนไขสิทธิ ตรวจเหตุผล ถ้ามีหลักฐานให้ยื่นอุทธรณ์

เช็กลิสต์ต่อเคส ก่อนกดส่ง

  • สิทธิ = UC ณ วันรับบริการ
  • มี Authen Code บน visit นี้ ไม่ซ้ำกับ visit อื่น
  • นอกเขต: มีเลขใบส่งตัว
  • มี Dx หลัก รหัส ICD-10 ถูกต้อง
  • หัตถการลง ICD-9-CM ครบ
  • มีเลขใบประกอบวิชาชีพแพทย์
  • ยาทุกตัว map รหัสมาตรฐานแล้ว
  • ค่าใช้จ่ายแยกหมวดครบ ยอดรวมตรงกัน
  • IPD: วันเวลา admit / discharge และสถานะจำหน่ายครบ
  • IPD: สรุปชาร์ตและจัดกลุ่ม DRG แล้ว
  • ยังอยู่ในกำหนดส่ง
  • visit / AN นี้ยังไม่เคยส่งผ่าน

หมายเหตุ: ขั้นตอนนี้สรุปตามแนวทางของ สปสช. สำหรับสิทธิ UC ทั่วไป เงื่อนไขปลีกย่อย (ประเภทบริการ, ข้อยกเว้นการยืนยันตัวตน, กำหนดส่ง, อัตราจ่าย) เปลี่ยนตามประกาศแต่ละปีงบประมาณ ให้ยึดคู่มือ e-Claim และคู่มือการขอ Authen ฉบับล่าสุดของ สปสช. เป็นหลัก ชื่อเมนูในแต่ละด่านของ HA.OS ยังไม่ได้ใส่ไว้ในหน้านี้
